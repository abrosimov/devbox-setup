# Trace fixtures

Hand-written fixtures that exercise `TraceOrders.tla` itself, one protojson-encoded
`orders.trace.v1.Event` per line. They are not recordings of a system and prove nothing about one.

| File | Expected | Purpose |
|------|----------|---------|
| `happy-path.jsonl` | accepted | every action matched, snapshot checked |
| `ship-before-pay.jsonl` | rejected at line 2 | `Ship` is not enabled for an unpaid customer |

Recordings of a real implementation are produced by the scenario harness into a gitignored
`.runs/` directory and regenerated by the test that needs them. A recording is committed only as
evidence attached to a finding, with its provenance (scenario, commit, date) in the report, and is
never edited.
